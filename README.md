# Hint First, Then Explain

Hint First, Then Explain is a study partner for adults working through one textbook chapter on their own: Chapter 6, "Learning," of OpenStax *Psychology 2e* (CC BY 4.0). The reading sits on the left, one section at a time, and the tutor sits on the right. Ask it anything and you get a short answer drawn only from the chapter, with every sentence linked to the paragraph it came from, so you can check it yourself. Off-topic questions are politely declined, and each answer is checked against the paragraphs it cites before you see it.

When you finish a section, its practice questions open one at a time. You answer first and say how sure you are, and only then see the result. If you're stuck, help comes in steps: a hint, a bigger hint, then the worked answer. After a wrong answer the tutor points you back to the reading, and that pointer fades as you go, from highlighting the paragraph to naming only the section. At the end of each section, a short summary shows what's worth another look and where you knew more than you felt. A 12-question pre-test before you start and a post-test at the end, covering every learning objective in the chapter with the reading and tutor hidden, show how much you learned.

Built with Streamlit and Google Gemini for CS6460 Educational Technology at Georgia Tech. Parts of this project were built with help from Claude. To run it locally, install `requirements.txt`, add a `GEMINI_API_KEY` to `.streamlit/secrets.toml`, and run `streamlit run app.py`. Without a key, the app still works and quotes the reading directly.
